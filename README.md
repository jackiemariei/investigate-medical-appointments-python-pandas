# Investigating Medical Appointment No-Shows

## Project Overview

This project explores a dataset of medical appointments in Brazil to investigate factors associated with patients missing their scheduled appointments.

Using Python, I explored patient demographics, appointment details, and health-related information to look for patterns that may help explain why some patients do not attend their appointments.

## Project Questions

- What percentage of scheduled medical appointments resulted in no-shows?
- Are no-shows associated with patient age or gender?
- Does receiving an SMS reminder appear to be associated with appointment attendance?
- Are there patterns related to waiting time between scheduling and the appointment date?

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Process

1. Loaded and reviewed the appointment dataset.
2. Checked the data for missing values, duplicates, and data quality issues.
3. Cleaned and prepared the data for analysis.
4. Explored patient characteristics and appointment information.
5. Created visualizations to examine patterns associated with missed appointments.
6. Summarized findings and limitations.

This project focuses on exploring associations in the dataset. The findings do not establish that any single factor causes a patient to miss an appointment.
